📚 Algorithm Architecture Comparison

Token Bucket vs. Sliding Window Log

🪣 Token Bucket Algorithm

Calculates continuous token refills over microsecond delta intervals. Allows temporary initial burst capacity up to bucket size while guaranteeing a steady average consumption rate.

⏱️ Sliding Window Log Algorithm

Tracks exact request microsecond timestamps in a sliding log array. Automatically evicts expired timestamps older than window duration. Prevents double-capacity window edge exploitation.
