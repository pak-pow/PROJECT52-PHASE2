# Week 16: Blog Platform (Static)

**Category:** Frontend Architecture | **Status:** Completed

## About

Before building dynamic, database-driven applications, it is important to master the fundamentals of multi-page layout and information architecture. This project is a static blog built entirely with HTML, CSS, and a small amount of JavaScript for interactivity like the dark/light theme toggle.

The site contains four distinct pages — Home, About, Posts, and a Roadmap — each properly linked and sharing a single stylesheet. This exercises CSS architecture skills: keeping styles consistent and DRY across multiple pages without a framework.

## What It Does

A fully responsive, multi-page static blog site with semantic HTML, a shared stylesheet, and a dark/light mode toggle.

## Learning Objectives

- Semantic HTML5 structure for accessibility and SEO
- CSS architecture across multiple linked pages
- Responsive layouts using flexbox and grid
- Basic JavaScript for theme toggling without a framework

## Project Structure

```
week16_static_blog/
├── index.html      # Home page
├── about.html      # About page
├── posts.html      # Blog posts listing page
├── roadmap.html    # Project 52 roadmap page
├── style.css       # Shared stylesheet for all pages
└── theme.js        # Dark/light mode toggle logic
```

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (no frameworks)
